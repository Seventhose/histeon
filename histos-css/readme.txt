Il framework CSS libero di Histeon, per qualsiasi sito WordPress.

== Description ==
Token fluidi (testi e spazi che scalano con lo schermo), palette OKLCH con le sfumature e il colore leggibile sopra ogni colore, classi di utilità, recipes, e un pannello in popup che si apre su qualsiasi pagina (Alt+Maiusc+H) e mostra subito le modifiche. Nell'editor a blocchi, la palette e le dimensioni del testo sono quelle del sito.

Nessuna licenza, nessun servizio esterno, nessun dato inviato. Con Histeon attivo, questo plugin resta fermo: Histeon lo include già.
