# Histeon

Builder visuale per WP, libero e senza chiavi di licenza.

Questo repository pubblica le **release**: niente sviluppo qui. Ogni release contiene `xb-<versione>-<commit>.zip` (il plugin), `xb-blank-…zip` (il tema di base), le firme `.minisig`, `SHA256SUMS` e l'archivio dei sorgenti `histeon-<versione>-sorgenti.tar.gz`.

## Aggiornamenti

Il plugin si aggiorna da solo da questo repository: in **Histeon → Impostazioni → Aggiornamenti** scrivi `Seventhose/histeon` e la chiave pubblica di firma. Accetta solo pacchetti firmati.

Prima di installare, controlla l'impronta del file con `SHA256SUMS` (`sha256sum -c SHA256SUMS`).

## Licenza e sorgenti

GPL-3.0-or-later: il testo è in `LICENSE`. I sorgenti completi di ogni versione sono nell'archivio allegato alla sua release.
