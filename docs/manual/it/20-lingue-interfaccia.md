# L'interfaccia in italiano e in inglese

Histeon è scritto in italiano ed è disponibile anche in inglese. Questo capitolo spiega come sceglie la lingua in cui ti parla, e cosa resta fuori da questa scelta.

> Qui si parla della lingua dell'**interfaccia**: menu, pulsanti, messaggi. Per pubblicare il **sito** in più lingue serve Lingua Bridge: vedi [Siti in più lingue](#it-multilingua).

## Come si sceglie la lingua

Histeon usa la stessa lingua di WordPress per te:

1. la lingua del tuo **profilo** (**Utenti → Profilo → Lingua**);
2. se il profilo non ne sceglie una, la lingua del **sito** (**Impostazioni → Generali → Lingua del sito**).

Poi la regola è semplice:

| La tua lingua in WordPress | Histeon ti parla in |
|---|---|
| Italiano | Italiano |
| Inglese | Inglese |
| Qualsiasi altra (tedesco, francese, spagnolo…) | Inglese |

Chi usa WordPress in tedesco o in francese legge quindi l'inglese, non l'italiano: è la lingua più probabile da capire. Se il sito ha una traduzione di Histeon proprio per la tua lingua, Histeon usa quella.

## Cambiare lingua

Ogni persona può avere la sua lingua, sullo stesso sito:

1. Apri **Utenti → Profilo**.
2. In **Lingua** scegli quella che preferisci.
3. Salva il profilo e ricarica il builder.

Un collaboratore straniero può così lavorare in inglese mentre tu continui in italiano. La scelta non cambia nulla del sito pubblico.

## Dove vale

La stessa regola vale per tutte le parti di Histeon, ognuna con le sue traduzioni:

- **Histeon**: le schermate di amministrazione, il builder e le schede di Histeon nell'editor a blocchi;
- **Histeon CSS**, il framework e il suo pannello;
- **Lingua Bridge**, il modulo delle lingue;
- **Static Bridge**, il modulo del sito statico;
- **Fondamenta**, il tema di base, e **XB Blank**, il tema di compatibilità.

Valgono sia quando li usi come moduli di Histeon, sia come plugin separati.

## Cosa non cambia con la lingua

Alcune cose restano uguali in tutte le lingue, perché non sono testi dell'interfaccia:

- **I nomi tecnici:** classi CSS, variabili, nomi dei permessi (`xb_build`, `xb_publish`), la sintassi delle espressioni e del codice.
- **I nomi dei prodotti:** Histeon, Histeon CSS, Lingua Bridge, Static Bridge.
- **Le istruzioni per gli agenti IA:** il manuale e le istruzioni che il connettore passa all'agente restano quelle originali.
- **Il contenuto del sito:** i testi delle tue pagine, e anche i testi già pronti dei temi Fondamenta e XB Blank (come «Pagina non trovata»), sono contenuto, non interfaccia. Li traduce chi gestisce il sito, anche con Lingua Bridge.

## Le parole in inglese

Se lavori con colleghi che usano l'interfaccia in inglese, ecco come si chiamano le cose principali:

| Italiano | Inglese |
|---|---|
| sviluppo, in sviluppo | development, in development |
| online, produzione | live |
| pubblicare, release | publish, release |
| bozza | draft |
| componente | component |
| tela | canvas |
| foglio di stile | stylesheet |
| selettore, classe | selector, class |
| stili globali | global styles |
| tipo di contenuto, campo | content type, field |
| sorgente dati | data source |
| media query con nome | named media query |
| query dei loop | loop query |
| anteprima | preview |
| ripristina | restore |
| Annulla, Ripeti | Undo, Redo |
| controlli | checks |
| trasloco del sito | site move |
| sito statico, copia statica | static site, static copy |
| memoria di traduzione | translation memory |
| selettore di lingua | language switcher |

> Le scorciatoie da tastiera non cambiano con la lingua dell'interfaccia: [[Ctrl+K]] apre i comandi sia in italiano sia in inglese. Vedi [Scorciatoie da tastiera](#it-scorciatoie).
