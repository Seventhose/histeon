# Histos 0.3.6

- **Gli archivi di una tassonomia mostrano anche i tipi senza pagine proprie.** Un tipo con «pagine proprie» spento resta fuori dalla ricerca, e WordPress riempie l'archivio di un termine solo con i tipi della ricerca: le sue voci sparivano dagli archivi delle tassonomie pubbliche a cui appartengono, mentre il conteggio del termine le contava. Su un sito di prova le pagine di un archivio per anno (`/anno/2019/`…) erano vuote. Ora la query principale di quegli archivi aggiunge quei tipi; la ricerca e le query che nominano i loro tipi restano com'erano.
