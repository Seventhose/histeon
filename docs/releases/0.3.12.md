# Histeon 0.3.12

- **Nuovo nome.** Histos si chiama ora **Histeon**: nel menu di WordPress, nel builder, nei messaggi, nel manuale e nella documentazione per gli agenti. Anche il framework CSS cambia nome visibile, da Histos CSS a Histeon CSS. Il nome viene sempre da ἱστός, il telaio greco.
- **Niente cambia per i siti esistenti.** Il nome vecchio resta dove è scritto nei dati e nei protocolli: gli attributi `data-histos`, i formati dei file (`histos-static-project`, `histos-transfer-markup`), le intestazioni `X-Histos-*` del collegamento con Histeon Publish, il nome del generatore nei trasferimenti, lo slug `xb` del plugin e quello `histos-css` del framework. Pagine, release, progetti e collegamenti già fatti continuano a funzionare senza migrazione.
- I commit di sviluppo inviati da Histeon Publish prima del cambio di nome («Invio da Histos CMS») si riconoscono ancora come invii.

Le release fino alla 0.3.11 restano descritte con il nome di allora.
