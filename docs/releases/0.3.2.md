# Histos 0.3.2

Il numero di versione cresce perché i siti riconoscano l'aggiornamento: dalla 0.3.1 (22 ottobre) il plugin è cambiato molto, e le build intermedie portavano ancora 0.3.1.

## Cosa conta per chi usa Histos Publish

- **Gli stessi nomi di Publish.** I template di un progetto inviato da Histos Publish leggono i dati come in Publish:
  - la radice è `page`, e `props.page` in un componente;
  - un articolo ha `publishedAt` e `updatedAt`, oltre a `date`;
  - un termine ha `label`, oltre a `name`.
- **I loop decidono `limit` e `offset` su ogni query**, con le stesse precedenze di Publish: un parametro proprio della query vince su `limit`, `offset` vince sempre.
- **Framework:** un progetto senza framework scelto porta Histos CSS. Senza ACSS non si caricano i fogli di una prova di ACSS.

Le altre modifiche dal 22 ottobre non hanno una nota propria.
