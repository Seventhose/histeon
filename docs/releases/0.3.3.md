# Histos 0.3.3

- **Le parti di template vedono la pagina.** La Testata e il Piè leggono `props.page` e `page` della pagina in cui stanno, come promette `docs/spec/templates.md` §5: una voce di menu si segna attiva con `props.page.slug == "contatti"` o `page.url`. Prima ogni test del genere dentro una parte valeva falso, e il menu non segnava mai la sezione (trovato sul sito di prova).
- **I componenti leggono `page`, come in Histos Publish.** `props.page` resta delle loro props.
