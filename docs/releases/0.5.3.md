# Histeon 0.5.3

- **Copia di sicurezza prima di ogni aggiornamento di Histeon** (cartella del plugin e tabelle di Histeon), con «Torna alla versione di prima» in Histeon → Impostazioni → Copie di sicurezza di Histeon. Se la copia non riesce, l'aggiornamento si ferma.
- **Link a un file della libreria:** nel pannello Proprietà di un link, «Scegli un file dalla libreria…» per un PDF o un'immagine.
- **Sicurezza:**
  - il markup che viaggia fra Histeon Publish e WP ha un elenco chiuso di attributi anche per i tag HTML di sempre, e rifiuta gli attributi `data-*` che librerie diffuse eseguono come codice;
  - la pulizia dei blocchi nell'editor a blocchi ricostruisce solo gli elementi ammessi, senza rileggere l'HTML;
  - lo staging accetta pacchetti solo dall'indirizzo con cui è stato abbinato;
  - «è negli upload» si decide dal percorso reale del file;
  - un blocco WP tenuto intero non entra più in SVG, select o textarea;
  - un filtro ha al massimo 256 condizioni.
- **Ritorno a una release precedente:** avvisa quando rimette online contenuti che nel frattempo sono stati ritirati.
- **Riassunto SEO** con il contesto della pagina giusta.
- **Meno memoria** per l'elenco delle modifiche (da 51 a 2 MB su 150 pagine grandi).
- **Moduli:**
  - Lingua Bridge 1.5.10: le pagine tradotte si aggiornano con gli incrementali di Static Bridge;
  - Static Bridge 2.2.11: alla riattivazione toglie le copie dei contenuti ritirati, e riscrive le pagine tradotte invece di toglierle (difetto della 2.2.9 e 2.2.10).
