# Histeon 0.5.15

Nomi più chiari nel pannello CSS e nelle ricette, testi dell'interfaccia e delle note d'esportazione più precisi, documentazione riletta.

- **Mini GUI «Stile compatto».** Accanto al pulsante «Mini GUI» si sceglie fra lo stile di Histeon (gruppi e righe) e lo «Stile compatto», la striscia di gruppi di pulsanti piccoli che compaiono solo quando servono. Funziona come prima; chi aveva già scelto la striscia la ritrova scelta dopo l'aggiornamento, senza fare niente.
- **Nomi alternativi delle ricette.** Una ricetta si trova e si scrive anche con un nome alternativo (per esempio `@auto-grid` per `@griglia-auto`, anche nella forma `?nome`). Nel pannello Ricette la ricerca dice «Cerca (anche coi nomi alternativi)» e il suggerimento di una ricetta elenca i suoi «Nomi alternativi».
- **Testi più precisi.** Nell'esportazione verso Etch, le note su ciò che non si esporta (condizioni, slot, indice del loop, props con liste o oggetti, schema delle props, loop su preset senza una query equivalente) dicono semplicemente che l'esportazione non li supporta. Nelle scelte su dove va il sistema di design di Automatic.css, Histeon CSS è «Nessun plugin esterno» e Core Framework «Open source». Traduzioni inglesi allineate.
- **Documentazione.** Specifiche, manuale (italiano e inglese) e guida per gli agenti riletti e allineati ai nomi nuovi.
- Nessun cambiamento nel comportamento del builder, nei contenuti salvati o nelle API. Static Bridge resta alla 2.5.0, Lingua Bridge alla 1.14.0, Fondamenta alla 0.2.1, XB Blank alla 0.4.0. Requisiti: WP 6.9 o superiore, PHP 8.3 o superiore (8.4 per Static Bridge).
