# Histos 0.3.1

Il builder regge le pagine molto grandi.

## Cosa cambia

Su una pagina di prova di circa 15.000 blocchi:

| | 0.3.0 | 0.3.1 |
|---|---|---|
| Apertura | 2,25 s | 0,85 s |
| Selezione di un elemento | 360 ms | ~40 ms |
| Memoria del builder | 342 MB | ~50 MB |

- **La struttura disegna solo le righe in vista.** Oltre 300 righe si disegnano solo quelle visibili. Restano disegnate anche quelle che si stanno trascinando o che hanno il focus. La tastiera arriva anche alle righe non disegnate. Sulle pagine normali la struttura funziona come prima.
- **Selezione e passaggio del mouse** aggiornano solo le righe interessate.
- **Le modifiche non copiano più l'intera pagina**, né per la storia di Annulla né per il pannello HTML.

Dettagli e misure in `docs/spec/performance.md`.

## Moduli inclusi

Lingua Bridge 1.5.1 e Static Bridge 2.1.0, verificati per SHA-256 (`modules.json`), spenti di serie.

## Requisiti

WordPress 6.9 o superiore, PHP 8.3 o superiore. Static Bridge come modulo richiede PHP 8.4.
