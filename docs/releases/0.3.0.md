# Histos 0.3.0

Modalità cliente, libreria di sezioni condivisa fra siti e Fluent Forms dentro il builder.

## Cosa cambia

- **Modalità cliente.** Nuovo ruolo «Cliente Histos» e capacità `xb_edit_content`: il cliente apre il builder e cambia solo testi, immagini e testi alternativi. Struttura, classi, stili, script e schema restano bloccati, sia nel builder sia sul server (REST e salvataggi di WordPress). Il cliente non pubblica.
- **Libreria di sezioni.** Si salva l'elemento selezionato, con gli stili delle sue classi, e lo si inserisce in qualsiasi pagina passando per la finestra di incolla, che gestisce i conflitti di classi. La libreria passa da un sito all'altro come file `.xblibrary` con impronta SHA-256. Ogni sezione viene ricontrollata e ricostruita. Importazioni ed eliminazioni finiscono nel Registro. È riservata a chi costruisce (`xb_build`).
- **Fluent Forms nel builder.** Se Fluent Forms è attivo, il menu Inserisci elenca i moduli e li inserisce con il blocco di Fluent Forms. «Modifica il modulo» e «Nuovo modulo Fluent Forms…» aprono l'editor di Fluent Forms dentro Histos. Valgono i permessi di Fluent Forms. Histos non crea moduli propri.
- **Disinstallazione più pulita**: vengono rimosse anche le opzioni del collegamento staging → produzione, la libreria, il ruolo cliente e la sua capacità.

## Moduli inclusi

Lingua Bridge 1.5.1 e Static Bridge 2.1.0, verificati per SHA-256 (`modules.json`), spenti di serie.

## Requisiti

WordPress 6.9 o superiore, PHP 8.3 o superiore. Static Bridge come modulo richiede PHP 8.4.
