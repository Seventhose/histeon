# Histeon 0.5.1

- **Un prototipo Histeon in un file si importa così com'è.** In Histeon → Release, «Converti una pagina HTML» riconosce un file con `data-histos-prototype="1"` e lo importa con template, componenti, contenuti e loop, nel progetto Histeon del sito, invece di convertirlo come una pagina qualunque. Le immagini `data:` arrivano con il file; quelle `https` le scarica il browser quando il sito che le ospita lo permette. Il convertitore è lo stesso di Histeon Publish.
- **Barra dell'agente.** Dopo una risposta d'errore smette di chiedere (progetti locali di Histeon Publish).
